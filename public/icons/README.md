## Creating Icons

You can use tools like:
- [Favicon Generator](https://favicon.io/)
- [PWA Asset Generator](https://www.pwabuilder.com/imageGenerator)
- [App Icon Generator](https://makeappicon.com/)

Or create them manually using image editing software.

## Design Guidelines

- Use the app theme color (#2563eb - blue)
- Include the 💪 emoji or a simple dumbbell icon
- Ensure icons work on both light and dark backgrounds
- Keep designs simple and recognizable at small sizes
- Use PNG format with transparency where appropriate

## Note

For testing purposes, you can create simple colored squares with the app initials "GT" until proper icons are designed.
